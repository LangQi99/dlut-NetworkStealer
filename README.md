## 简介

一个基于Python的网络工具。

适用欺骗仅认证MAC地址的校园网/企业网，可以主动、被动获取离线、在线的MAC地址，允许Windows设备修改网卡MAC地址。

- 如何理解ARP数据包
- 如何抓取ARP包
- 如何在Windows上修改网卡MAC地址
- Windows的MAC地址特殊要求
